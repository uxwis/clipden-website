# ClipDen 官网

独立的中文产品官网。以用户提供的 Figma 参考为视觉方向，采用中性石墨灰与玻璃质感，从新的窗口图标中提取蓝、青色作为强调色。内容最大宽度为 1280px，小屏幕自动收窄。首页使用产品介绍视频，标签拼片用于功能区、交互演示和收尾区。

纯 HTML / CSS / JavaScript，无需安装依赖。视频、封面、图片、图标、样式、脚本全部保存在本地；页面运行不依赖 Sites、Figma、Google Fonts 或外部 CDN。未发布本次修改。

## 本地预览

在此目录运行 `node server.mjs`，打开 http://127.0.0.1:4173。

`dist/` 是完整静态网站，将其中的文件上传到自己的 Web 服务器或静态托管即可。使用相对资源路径，支持放在域名根目录或子目录。`npm.cmd run check` 检查 JavaScript 语法。

## 内容与交互

- 首页、素材库演示、产品能力、可视化三步工作流、常见问题与版本信息。Hero 主视觉使用用户提供的 24.75 秒 1080p60 产品介绍视频，保留原始视频与音频编码，调整 MP4 索引以便渐进播放；默认静音循环，可暂停、打开声音或全屏观看。离开视口时暂停，用户主动暂停后不会自动恢复。
- 演示素材库支持关键词搜索、分类筛选、标签拼片与素材详情。影像、时长、分辨率、标签和摘要均为示例，不读取用户本地视频。
- 标签拼片复用桌面端 `desktop/ui/tag-mosaic.js` 的圆角多边形算法，排版沿用原 Hero 的拼片构图，并根据标签数与屏幕宽度分组。标签搭配图片、图标与深灰 / 浅蓝 / 青色背景，仍支持搜索与点击筛选。
- “城市建筑”标签使用简洁的灰色建筑画面。问答合并离线使用与视频上传说明，简化格式与系统支持文案，收费说明为“当前体验尚不完善，短期内没有收费计划”。新增未签名下载提示说明，区分应用信誉警告与明确的病毒检测结果，不作绝对安全保证。相关说明参考 [Microsoft SmartScreen 文档](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。
- 页脚“联系我”通过 `mailto:uxwis@icloud.com` 调用默认邮件应用撰写邮件，不会自动发送。
- 使用原生 dialog、键盘可操作的标签页、焦点恢复和手机菜单。
- 视频和标签共用同一标题行与内容起点，在固定尺寸的窗口内切换并各自内部滚动；桌面端窗口高 660px，中等屏幕 620px，手机端 520px。示例说明位于标题行右侧，结果数量仅通过无障碍状态文本播报。
- 功能区由同一画布分割为三块圆角拼片，共用边界并保留均匀拼缝。桌面端相互嵌合，小屏纵向拼接；照片、收纳与本地存储示意融入不规则轮廓。三步工作流采用连线、步骤徽标、产品配图与少量文字。
- 功能区 01 使用清晰的原比例画面、人物和山川识别框、AI 自动生成的标签与摘要，展示从画面到线索的过程；03 与 02 共用深色背景，配图使用协调的蓝灰色玻璃材质，标题下移 12px，移除“原文件”字样。关系图虚线按可见元素的边缘测量并连接。页脚保留弱化的无外框标识、创作者小红书链接和版权，移除描边大字；问答说明 Windows 支持、Mac 版需求评估，Eagle 比较使用用户提供的文案并自然换行。
- 中文最小字号为 12px，英文最小字号为 10px；SVG 配图中的文字会按实际显示比例调整。桌面与手机的两种演示视图保持相同标题行、内容起点及窗口尺寸。
- 各模块离开视口后重置，再次进入时重新播放进场动效；工作流和问答轻微错开，主视觉与功能配图随滚动产生小幅位移。01 包含轻微扫描及标签生成动效。演示标签页无外框，在进入视口后显示指针和点击光晕，用户点击或键盘操作后停止；切换视图有轻微过渡，不会自动改变选中标签。
- 按用户要求，页面始终开启动效，不再读取旧动效设置，也不保留开关入口。使用原生 IntersectionObserver 和 requestAnimationFrame，不依赖动画库。
- 当前版本信息基于桌面项目 v0.3.1。页头、首屏和页尾的下载入口均连接到用户提供的 Windows 安装包地址 `https://clipden-download.wis-mailto.workers.dev/download/win`，使用可键盘操作的原生链接。
- 图片鸣谢记录在 `dist/assets/credits.json`。

本目录独立于桌面程序，未改动桌面程序的业务代码。
