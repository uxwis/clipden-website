# Owl 官网

独立的中文产品官网，沿用 Owl 桌面端猫头鹰标识与炭黑、暖白、鼠尾草绿。纯 HTML / CSS / JavaScript，无需安装依赖。

## 本地预览

在此目录运行 `node server.mjs`，打开 http://127.0.0.1:4173。

`dist/` 是完整静态网站，可直接部署。`npm.cmd run check` 检查 JavaScript 语法。

## 内容与交互

- 首页、产品能力、三步工作流、常见问题与版本信息。
- 演示素材库支持关键词搜索、分类筛选、标签拼片与素材详情。影像、时长、分辨率、标签和摘要均为示例，不读取用户本地视频。
- 标签拼片算法来自桌面端 `desktop/ui/tag-mosaic.js`。
- 使用原生 dialog、键盘可操作的标签页、焦点恢复、手机菜单及减少动态效果偏好。
- 当前版本信息基于桌面项目 v0.3.1。用户尚无公开下载链接，因此主按钮通向交互演示，未提供虚构下载入口。正式发布后可更新 `dist/index.html` 中版本弹窗和 CTA。
- 图片鸣谢记录在 `dist/assets/credits.json`。

本目录独立于桌面程序，未改动桌面程序的业务代码。
